\begin{abstract}
We present \emph{UCO Sensor}, a code-quality analysis platform that
formalizes five core invariants over a spectral representation of
program metric trajectories, with a Hamiltonian Monte Carlo (HMC) repair
loop, formal Granger F-test causality matrices, and a unit-budget
multi-tenant billing layer.  Our contribution is the \emph{executable
specification} of these invariants: each is a Python predicate whose
violations are detected at runtime and pinned by a regression suite.
We evaluate on a corpus of five OSS repositories
(Flask, Django, requests, +2 TBD) and show that the system identifies
prediction bias, propagation pathways, and remediation opportunities
that single-snapshot SAST tools (SonarQube, CodeQL, Infer) miss.
\end{abstract}

\section{Five Core Invariants}
\label{sec:invariants}

We isolate five invariants of the UCO Sensor system.  Each is
implemented as a Python predicate in
\texttt{governance/invariants.py}, and each is pinned by at least three
regression tests in \texttt{tests/test\_marco\_m59.py} (TW01-TW15).

\begin{invariant}[APS preservation under repair]
\label{inv:i1}
Let $p$ be a patch accepted by HMC with \texttt{preserve\_aps=True}.
Then $\mathrm{APS}(p) \geq \mathrm{APS}(\mathrm{source})$.
\end{invariant}

\begin{invariant}[Severity monotone under repair]
\label{inv:i2}
For any accepted patch $p$, $|\{f \in \mathrm{findings}(p) :
\mathrm{sev}(f) \in \{\mathrm{CRIT, HIGH}\}\}|$ does not strictly
exceed the same count for the original source.
\end{invariant}

\begin{invariant}[HMC convergence bound]
\label{inv:i3}
For any HMC run with \texttt{n\_steps} $\geq 1$ and finite source, if
the run returns \texttt{status="OK"}, then the final Hamiltonian
satisfies $H_{\mathrm{final}} \leq H_{\mathrm{initial}}$.
\end{invariant}

\begin{invariant}[Propagation symmetry at zero lag]
\label{inv:i4}
For any two channels $a, b$ in the propagation matrix at lag $\tau = 0$,
$\mathrm{cov}(a, b) = \mathrm{cov}(b, a)$ within $\epsilon = 10^{-9}$.
\end{invariant}

\begin{invariant}[Period reset atomicity]
\label{inv:i5}
Let two concurrent invocations of \texttt{reset\_period\_if\_rolled}
target the same tenant.  If the first call returns \texttt{True}
(i.e.\ performed the reset), the second returns \texttt{False}.
\end{invariant}
